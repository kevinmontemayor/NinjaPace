#  # NinjaPace Support

Need help with NinjaPace?

For bug reports, feature requests, or general feedback:

- Open an issue: https://github.com/kevinmontemayor/NinjaPace/issues
- Email: k.montemayor1@gmail.com

When reporting an issue, please include:
- iPhone model
- Apple Watch model
- iOS/watchOS version
- NinjaPace version
- A short description of the problem

Thank you for using NinjaPace!
